# Guard Suffering 🛡️⚔️

A 3D third-person action game developed using Unity Engine and C#. 

## Technical Features Implemented
* Custom Enemy AI behaviors (Pathfinding and Attack states).
* Dynamic combat system and precise player movement logic.
* Integrated sound effects and particle systems.
